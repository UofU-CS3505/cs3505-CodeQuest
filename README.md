# Code Quest

A block-based coding education game built with Qt/C++.

Drag and drop code blocks to solve puzzles and guide a character through each level. No typing required, just pick the right blocks, arrange them in order, and hit Run to see your code come to life.

## Key Features

* **Visual Block Workspace:** Implements an intuitive drag-and-drop workspace UI allowing users to sequence control flow, loops, and movement commands.
* **Real-Time Execution & Highlighting:** Visually tracks execution by highlighting active blocks in real-time as the interpreter evaluates logic.
* **Physics & Collision Integration:** Utilizes **Box2D** physics handling for object interactions, environmental navigation, and obstacle avoidance.
* **Robust Syntax & Logic Checking:** Includes custom structural checks (such as loop brace validators and scope rules) to ensure scripts run reliably.
* **Level Progression & Save Systems:** Manages distinct game canvases, win/loss states, and persistent user save files.
